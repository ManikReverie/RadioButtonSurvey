# Radio Button Survey
## Project Overview
A simple Android survey app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 14). It uses RadioButtons to collect user responses and displays the selected option.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Survey question with four options
- RadioGroup for single selection
- Submit button
- Displays the selected response
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully collects and displays the user's selected response using RadioButtons.
